🚗 Car Dheko - Used Car Price Prediction
A machine learning-based Streamlit app to predict used car prices based on features like brand, year, mileage, fuel type, and more.

📌 Objective
Build and deploy a regression model to estimate used car prices from CarDekho data across different cities.

🛠️ Tech Stack
Python, Pandas, NumPy

Scikit-Learn (ML models)

Streamlit (Web App)

Matplotlib, Seaborn (EDA)

📊 Workflow
Data Cleaning: Combined city-wise data, handled missing values, removed units, encoded categories, normalized features, removed outliers.

EDA: Visualized distributions, correlations, and selected key features.

Modeling: Trained multiple regressors (Linear, Tree-based), tuned hyperparameters.

Evaluation: MAE, MSE, R² Score.

Deployment: Built interactive Streamlit app for real-time predictions.

✅ Deliverables
Cleaned dataset & model code

EDA visuals

Final trained model

Streamlit app

Documentation
